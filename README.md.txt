# Basic Power BI Import – Task 39

## Project Overview
This project is created as part of the Veda Technology Data Analytics Track.

The main objective is to import the Superstore dataset into Power BI and create a simple one-page interactive report.

## Tools Used
- Microsoft Power BI Desktop
- Superstore Dataset

## Project Visuals
1. Sales by Category – Shows sales for different product categories.
2. Profit by Region – Displays profit across different regions.
3. Sales by Segment – Shows sales distribution across customer segments.

## Key Learnings
- Importing datasets into Power BI.
- Understanding data fields.
- Creating bar, column and donut charts.
- Formatting visuals.
- Designing a one-page report.

## Project Deliverables
- Power BI report (.pbix)
- Three data visualizations
- README documentation
